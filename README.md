# Mon3tr 桌宠（Mon3trPet）

![预览](docs/images/preview.gif)

Windows 桌面宠物，基于 Tauri 2 + Rust + WebView2。
素材取自《明日方舟》的干员 **Mon3tr（M3）**。

大部分时间安静地待机，会自己走动、坐下、休息；可以点它、跟它说话、问它天气。

## 下载

到 [Releases](../../releases) 页面下载 `Mon3trPet-x.y.z-win64.zip`（约 19 MB），
**解压即用，无需安装**。

解压后是这样：

```
Mon3trPet\
├─ Mon3trPet.exe      启动器，仅 3.8 MB
├─ assets\            角色动画（342 帧 WebP，约 14 MB）
└─ audio\             语音（38 条 Opus，约 3.4 MB）
```

> 素材是**独立文件**，不是塞在 exe 里的 —— 所以 exe 只有 3.8 MB，
> 改素材也不必重新编译。但**三者必须放在一起**，不要单独移动 exe。

> **请解压到可写目录**（桌面、`D:\Tools\` 等）。
> 程序会在 exe 同目录生成 `pet-config.json` 与 `webview-data\`，
> 放在 `C:\Program Files\` 会因权限不足导致配置存不下来。

**系统要求**：Windows 10/11 64 位；需 WebView2 运行时（Win11 及新版 Win10 已内置）。

首次运行 Windows 可能弹出 SmartScreen 提示（程序未做代码签名），
点「更多信息」→「仍要运行」即可。

## 操作

| 操作 | 效果 |
|---|---|
| 拖动角色 | 移动窗口位置（会暂停自主行为几秒）|
| 单击角色 | 播放「点击」特效 + 语音，播完自动回到待机 |
| 右键 | 打开菜单 |

窗口位置与缩放会自动保存，下次启动回到原位。

## 右键菜单

```
互动      交谈 / 天气 / 跟随鼠标 / 设置
动作      待机 / 行走 / 休息 / 坐下 / 点击特效
          随机行为一次 / 暂停自主活动
窗口      总在最前 / 点击穿透 / 尺寸 20%~100% / 移到屏幕底部
退出
```

「跟随鼠标」「坐下」是**切换式**的，按钮文字会跟着状态变
（跟随鼠标 ↔ 取消跟随、坐下 ↔ 起身）。

## 设置

右键 →「设置…」，包含三组：

| 分组 | 项 |
|---|---|
| 窗口 | 总在最前、点击穿透、尺寸滑条（20%~100%）、移到屏幕底部 |
| 声音 | 音量、语音语言（中文 / 日本語）、生日（月/日）、试听 |
| 所在地区 | 天气城市，最多 3 个（搜索后从候选列表点选）|

## 功能

| 功能 | 说明 |
|---|---|
| 自主行为 | 待机 / 行走 / 休息 / 坐下，随机触发，可调「性格」 |
| 语音 | 38 条中日双语，含节日与生日触发 |
| 天气 | 右键查询，气泡播报 + 语音，数据来自 Open-Meteo（无需 API Key）|
| 随机关心 | 待机时每 2~3 分钟说一句，50 条语句随时段加权 |
| 跟随鼠标 | 按光标方向移动，离得越远越快 |
| 点击穿透 | 按像素 alpha 判定，透明处不挡桌面图标 |

这些功能的**实现细节与取舍理由**见 [docs/DESIGN.md](docs/DESIGN.md)。

## 从源码构建

一条命令完成全流程（生成前端代码副本 → 转换素材 → 编译 → 打包）：

```powershell
powershell -ExecutionPolicy Bypass -File _work\build_release.ps1
```

产物在 `dist\Mon3trPet\`。

若只想编译 exe（素材已就绪）：

```powershell
cargo build --release --manifest-path desktop-pet\src-tauri\Cargo.toml
```

构建环境、完全离线构建、目录结构、如何扩充新动作，
见 [docs/BUILD.md](docs/BUILD.md)。
