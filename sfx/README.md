# 音效素材目录

把音效文件放在这里。当前**只是素材存放处**，尚未接入程序。

## 目录约定

```
sfx/
├─ click/          点击特效音
├─ talk/           交谈台词音（可按台词序号命名）
├─ move/           行走时的循环音（可选）
├─ rest/           休息时的音效（可选）
├─ ui/             菜单交互音（打开、选择等）
└─ ambient/        环境音 / 天气音（如雨声、风声）
```

子目录可按需创建，没有的就不建。

## 文件格式建议

| 用途 | 推荐格式 | 说明 |
|---|---|---|
| 短音效（点击、UI） | `.ogg` 或 `.wav` | WebView2 对 ogg/opus 支持良好 |
| 较长音频（环境、天气） | `.ogg` | 体积小，适合循环 |
| 台词 | `.ogg` | 建议统一采样率 |

**为什么不用 mp3**：mp3 有编码延迟，短音效听起来会「慢半拍」；
ogg/opus 或 wav 更适合交互音效。若已有 mp3，也可以先用，
后续接入时我再做转换。

## 命名建议

用**语义化名称**，便于在配置里引用：

- `click/ice_burst.ogg`
- `talk/greet_01.ogg`、`talk/greet_02.ogg`
- `ui/menu_open.ogg`

台词类建议带序号，方便随机抽取。

## 接入方式（后续）

等实现音效播放时，会把这里的文件同步到
`desktop-pet/web/sfx/`（运行时资源目录），
再通过一个配置表把「动作 / 事件」映射到具体音频文件，
与 `actions.json` 的思路一致——**数据驱动，加音效不用改代码**。

## 注意事项

- 注意音频版权，避免使用未授权素材
- 单个文件建议控制在几百 KB 内，避免拖慢启动
- 若同一音效有多种变体（避免重复感），用 `_01`、`_02` 区分
